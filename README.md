🏏IPL Analysis Dashboard
📘 Overview
Power BI is a business intelligence and data visualization tool by Microsoft that allows users to analyze data and share insights through rich, interactive dashboards and reports. Its powerful integration with a variety of data sources, intuitive interface, and robust features make it a leading tool for transforming raw data into meaningful insights.

✨ Key Features of Power BI:
1.DAX (Data Analysis Expressions): A powerful formula language used for creating custom calculations and measures.

2.Interactive Visualizations: Drag-and-drop interface to build stunning dashboards.

3.Real-time Data Monitoring: Refresh dashboards automatically with real-time data.

4.Custom Filters and Slicers: Empower users to view the data that matters most to them.

5.Seamless Integration: Works with Excel, SQL Server, SharePoint, Azure, and many more.

6.Data Modeling: Create relationships between tables and build advanced data models.

7.Mobile Accessibility: Dashboards are accessible on the web and mobile devices.

🏆 Project Description
This project presents an IPL Analysis Dashboard built with Power BI, providing deep insights into the Indian Premier League (IPL) across all seasons. It explores match results, player and team performances, and venue statistics using interactive visuals and DAX-powered calculations.

The core of this dashboard is driven by DAX queries, enabling advanced metrics, aggregations, and logic that power each visualization and KPI in the report.

📊 Dashboard Highlights
1. Season Filtering
Allows users to filter data based on individual IPL seasons.

Enables focused analysis on specific years (e.g., 2018, 2020).

🗂️ Use Case: Track changes in performance or team dynamics over time.

2. Season Champion
Displays the winning team for each season.

Uses DAX logic to extract and display the final match winner.

🏆 Use Case: Understand which teams have dominated historically.

3. Season Runner-Up
Shows the runner-up team for each season.

Extracted from match data using conditional DAX queries.

🥈 Use Case: Highlight near-miss performances and consistent contenders.

4. Total 6s
Total number of sixes hit across all matches.

Aggregated using DAX measures.

💥 Use Case: Gauge aggressive batting trends and audience excitement factors.

5. Total 4s
Shows the total number of boundaries (fours) across seasons.

Helps compare batting performances year-over-year.

🔥 Use Case: Identify power hitters or boundary-dense seasons.

6. Centuries
Displays the number of centuries scored across all IPL seasons.

Computed using DAX to count scores ≥100.

💯 Use Case: Measure individual player brilliance.

7. Half Centuries
Total number of scores between 50 and 99.

Helps in identifying consistent performers.

🧢 Use Case: Complement century data with supporting performances.

8. Total Matches
Total matches played across all seasons.

Essential to normalize and compare season-wide statistics.

📅 Use Case: Contextualizes runs, boundaries, and team performance per season.

9. Total Teams
Shows the number of teams that have participated in the IPL.

Accounts for team expansions and retirements.

🧑‍🤝‍🧑 Use Case: Understand league growth and competition history.

10. Total Venues
Displays the number of unique stadiums where IPL matches have been played.

Extracted using DAX distinct counts.

🏟️ Use Case: Visualize the geographical spread and popularity of IPL.
